# Feature list

Modeled on the feature set schools in Pakistan expect from a modern school management platform (attendance-first workflows, PKR fee challans, board-style result cards, parent communication).

## Included in this repo (working)

- Marketing landing page with PKR pricing tiers
- Admin dashboard with live KPIs and charts
- Students, Staff & HR management
- Daily attendance registers with absent-parent alert list
- Fee structures, monthly challan generation, collection with discounts, printable receipts, defaulter tracking
- Exam creation, marks entry, automatic grading scale (ممتاز 80%+ · جید جداً 70%+ · جید 60%+ · مقبول 50%+ · راسب below 50%), class positions, printable result cards
- Accounting ledger with automatic posting from fees & payroll, P&L summary
- Payroll runs
- Admission enquiry CRM with source attribution and one-click enrolment
- Behaviour log (internal note + parent message)
- Announcements
- Class timetables
- School profile, fee-structure and subject settings
- JSON backup/restore, CSV exports (students, staff, fees, ledger)
- REST API backend (Node.js, zero dependencies)

## Not included (roadmap)

- Hosted multi-user auth & roles
- Parent/teacher mobile apps (PWA planned)
- WhatsApp/SMS gateways
- Online fee payment (1BILL/1LINK, EasyPaisa/JazzCash APIs)
- Multi-branch tenancy
